Colformer Atlas 便携版

一、在另一台电脑打开
1. 把整个ZIP压缩包复制到另一台电脑，并完整解压。
2. 进入 Colformer_Atlas_Portable 文件夹，双击 index.html。
3. 推荐使用较新的 Chrome 或 Edge。首次读取大型序列及注释数据时，请稍等几秒。
4. 不要直接在压缩软件内部预览网页，也不要只复制 index.html。

二、包含什么
网页、75,701条序列浏览数据、位点注释数据、独立Hyp证据下载、4,283条先导训练序列下载及Hyp参考序列下载。
数据、样式和脚本都在本文件夹内，浏览和筛选不依赖原电脑、原项目路径或在线站点。访问外部论文和数据库链接需要联网。

三、如果浏览器限制本地文件
可安装Python 3后运行本文件夹的 open_atlas.py；它会自动选用空闲端口，只在本机启动服务并打开浏览器。
Windows也可双击 start_windows.bat。
macOS/Linux在终端进入本文件夹，运行：python3 open_atlas.py
关闭终端或按Ctrl+C即可停止服务。

四、文件结构
index.html：入口；about.html：方法与来源。
atlas.js、atlas.css：程序与样式。
data/：完整序列目录、序列分块及注释分块，请完整保留。
downloads/：训练序列与独立Hyp数据及其校验清单。
FILES_SHA256.json：便携包各文件SHA256，用于核对复制是否完整。

五、使用提示
默认显示完整收录序列。只看有Hyp筛选会隐藏没有Hyp注释的序列，点击“浏览当前范围全部序列”即可取消筛选。
主集29,663条是浏览目录，独立的保守先导训练包是4,283条。详细方法与来源在about.html。

本版按要求删除两处说明栏与网页日期标记；底层序列及注释数据保持不变。
